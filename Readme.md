# 🦺 EPI Detection com YOLOv8

Projeto de visão computacional para detecção de Equipamentos de Proteção Individual (EPI) utilizando YOLOv8.

---

## 🚀 Tecnologias utilizadas

* Python
* YOLOv8 (Ultralytics)
* OpenCV

---

## 📌 Objetivo

Desenvolver um sistema capaz de identificar automaticamente o uso de EPIs em ambientes industriais, como capacetes e coletes de segurança.

---

## 🧠 Como funciona

O modelo foi treinado com um dataset customizado e utiliza YOLOv8 para detectar objetos em imagens ou vídeos.
